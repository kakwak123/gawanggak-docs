# Android

지금 가장 집중하고 있는 단계예요.

## 끝난 일

- [x] 홈, 15초 맛보기, 녹음, 분석, 결과, 공유 카드, 설정 화면
- [x] 실제 폰에서 녹음부터 결과까지 한 번에 확인
- [x] 녹음을 보내기 전에 안내하고 동의 받기
- [x] Android 16(API 36) 대상으로 빌드
- [x] 16KB 메모리 페이지 대응
- [x] 버튼 터치 영역 48dp로 맞추기

## 실제 폰에서 확인할 일

- [ ] 녹음하는 동안 화면이 꺼지지 않는지
- [ ] 녹음 중에 뒤로 가면 먼저 물어보는지
- [ ] 다른 앱으로 넘어가도 그때까지의 녹음이 남는지
- [ ] 문제 구간을 눌러 내 노래와 음정 교정본을 비교해 듣기
- [ ] 앱에서 한 곡씩, 또는 전부 지우면 서버의 녹음도 지워지는지

## 출시 전에 남은 일

- [ ] 분석 서버를 클라우드에 공개하기
- [x] [개인정보 처리방침](../privacy-policy.md) 공개
- [ ] 권리와 개인정보 전문가 검토
- [ ] 스토어용 서명 빌드(AAB) 만들기
- [ ] 스토어 스크린샷과 데이터 보안 양식 작성
- [ ] 비공개 테스트: 테스터 12명이 14일 연속 참여
- [ ] Google Play 프로덕션 심사

테스터 조건은 [Google Play 개인 개발자 계정 규정](https://support.google.com/googleplay/android-developer/answer/14151465)을 따라요.
