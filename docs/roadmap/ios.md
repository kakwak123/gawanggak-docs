# iOS

Android 비공개 테스트에서 앱이 안정되면 시작해요. 앱이 Expo로 만들어져 있어서 화면과 로직 대부분을 그대로 쓸 수 있어요.

## 해야 할 일

### 준비

- [ ] 유료 Apple Developer 계정 만들기
- [ ] iOS 앱 식별자 정하고 앱 설정 추가하기
- [ ] [EAS Build](https://docs.expo.dev/submit/ios/)로 iOS 빌드 만들기. Windows에서도 클라우드로 빌드하고 제출할 수 있어요.

### 아이폰에서 다시 확인

- [ ] 녹음 품질과 마이크 권한 안내
- [ ] 전화나 다른 앱이 끼어들었을 때 녹음이 남는지
- [ ] 문제 구간 재생과 음정 교정 비교
- [ ] 공유 카드
- [ ] 화면 노치와 홈 표시줄에 가리는 곳이 없는지

### 베타

- [ ] [TestFlight](https://docs.expo.dev/submit/testflight/)로 내부 테스터에게 배포
- [ ] 외부 테스터로 넓히기

### App Store 심사

- [ ] 앱 개인정보 항목 작성
- [ ] 제3자 AI로 개인정보를 보낸다면 무엇을 누구에게 보내는지 알리고 먼저 허락 받기 ([심사 지침 5.1.2](https://developer.apple.com/app-store/review/guidelines/))
- [ ] 스크린샷과 설명 작성
- [ ] 심사 제출
