# 로드맵

가왕각은 Android를 먼저 출시하고, 같은 코드로 iOS까지 가요. 날짜는 확실해지면 적을게요.

<Stairs />

## 왜 이 순서인가요

- **Android가 먼저예요.** 개발과 실제 폰 시험이 Android에서 진행되고 있어요.
- **서버가 스토어보다 먼저예요.** 노래 분석은 서버에서 돌아가서, 서버가 공개돼야 다른 사람이 앱을 쓸 수 있어요.
- **iOS는 Android 테스트 뒤에 가요.** 앱은 Expo로 만들어서 대부분의 코드를 같이 쓰지만, 녹음과 재생은 아이폰에서 따로 확인해야 해요.
