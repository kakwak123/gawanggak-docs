# 공개 서버

가왕각은 노래를 폰이 아니라 서버에서 분석해요. 목소리를 분리하고 음정을 따라가는 모델이 폰에서 돌리기에는 무겁기 때문이에요.

## 준비된 것

- [x] 서버 이미지(Docker) 빌드
- [x] 한 사람이 너무 많이 보내지 못하게 하는 요청 제한
- [x] 동시에 몰려도 순서대로 처리하는 대기열
- [x] 파일 크기와 곡 길이 제한

## 남은 일

- [ ] 서버 이미지를 GPU 환경에서 실제로 실행해 보기
- [ ] 클라우드 GPU 호스팅 정하기
- [ ] HTTPS 주소 연결
- [ ] 녹음 저장 비용 줄이기
- [ ] 앱이 공개 서버를 바라보게 바꾸기

곡을 분석할 때만 GPU 비용이 나가도록, 쉬는 동안에는 꺼지는 호스팅을 우선 검토하고 있어요.
