# 내 목소리는 어떻게 다뤄지나요

:::note
쉽게 줄인 안내예요. 전체 내용은 [개인정보 처리방침](https://kakwak123.github.io/apps/singk-privacy)에 있어요.
:::

- **보내는 것.** 내가 부른 노래의 녹음을 분석 서버로 보내요. 처음 보내기 전에 앱에서 안내하고 동의를 받아요.
- **쓰는 곳.** 티어와 점수, 노래 닮은꼴을 계산하고 내가 문제 구간을 다시 듣는 데만 써요. AI 학습이나 광고에는 쓰지 않아요.
- **보관.** 녹음은 서버에 최대 90일 보관한 뒤 자동으로 지워요. 결과는 내 폰에 저장돼요.
- **지우기.** 앱에서 한 곡씩 또는 전부 지울 수 있고, 서버의 녹음도 같이 지워져요.
- **계정.** 로그인이 없어요. 이름, 연락처, 위치, 광고 식별자를 받지 않아요.
- **앱을 지울 때.** 계정이 없어서 앱만 삭제하면 서버의 녹음은 90일 뒤에 지워져요. 바로 지우려면 앱을 삭제하기 전에 "기록 전체 삭제"를 눌러 주세요.
- **외부 전달.** AI 레슨 문구를 켜면 음정 같은 측정 수치가 Anthropic으로 갈 수 있어요. 녹음과 곡 제목은 보내지 않아요.
