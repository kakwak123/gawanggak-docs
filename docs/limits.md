# 아직 못 하는 것

출시 전이라 부족한 부분을 그대로 적어 둘게요. 개선되면 이 목록에서 지워요.

- **일반인 노래가 실제보다 높게 나올 수 있어요.** 잘 부르는 일반인이 90점대로 올라가는 경우를 줄이는 중이에요.
- **90점대 안의 순서는 믿기 어려워요.** 가수급과 가왕급을 안정적으로 가르지 못해요.
- **울림 점수는 녹음 상태를 많이 타요.** 먹먹하게 녹음되면 실력보다 낮게 나올 수 있어요.
- **가성이나 힘없는 소리를 아직 잘 구분하지 못해요.**
- **내 음악 스타일을 판정하지는 못해요.** 그래서 닮은 가수들이 주로 부르는 장르를 대신 보여 줘요.
- **30초보다 짧은 녹음은 노래 닮은꼴이 덜 정확해요.** 1분 넘게 부르면 더 나아요.
