# 진행 기록

## 2026년 11월 21일

**앱**

- 새 디자인으로 홈, 맛보기, 분석, 결과, 공유 카드, 설정을 만들었어요.
- 일반인과 노래방 에이스 사이에 노래 꿈나무 단계를 넣어 8단계가 됐어요.
- 앱을 켜면 바로 홈이 나오고, 녹음을 멈추면 바로 전송돼요.
- 문제 구간을 눌러 내 노래와 음정 교정본을 비교해 들을 수 있어요.
- 녹음 중 화면 꺼짐, 뒤로 가기, 앱 전환으로 녹음을 잃지 않게 고쳤어요. 실제 폰 확인은 남아 있어요.
- 데이터 안내를 이용약관 화면으로 모았어요.

**서버**

- 공개 서버용 요청 제한과 대기열을 넣었어요.
- 녹음을 최대 90일 보관하고 앱에서 지울 수 있게 했어요.
- 보관 녹음 압축을 시험했지만 음정 교정 재생이 달라져서 적용하지 않았어요.

**측정**

- 내 목소리와 닮은 가수를 찾는 기능을 넣었어요.
- 음악 스타일 판정과 가성 구분은 시험 기준을 넘지 못해서 넣지 않았어요.
